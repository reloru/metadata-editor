# metadata-editor

Edit metadata in MP3 (ID3v2.3/2.4), WAV (LIST/INFO, id3 chunk), AIFF/AIFC (text chunks, ID3 chunk), FLAC (Vorbis comments, pictures), Ogg Vorbis and Opus (comments, edited within the existing header pages), M4A, MP4 and MOV (iTunes ilst), JPEG, PNG, WebP, GIF, HEIC/AVIF and TIFF/DNG files on-device. GIF: comments editable and addable, XMP/ICC/application blocks shown and deletable, frames untouched. Images: a Photo info group (caption, keywords, date taken) writes every EXIF and XMP copy at once; edit, add or remove any EXIF tag and any XMP property (JPEG/PNG/WebP/HEIC/DNG), remove the embedded thumbnail, remove GPS location without touching other EXIF, edit JPEG comments and PNG text chunks, delete metadata blocks. HEIC/AVIF and TIFF/DNG (including iPhone ProRAW): view EXIF/XMP, edit/add/remove EXIF tags (HEIC: edited EXIF is appended and its item location patched; DNG/TIFF: new values appended), remove GPS in place. A GPS timestamp that disagrees with Date taken (for example after editing the date) is flagged. MOV/MP4: QuickTime keys metadata shown (make, model, creation date, location) and location (keys, udta ©xyz, 3GPP loci) removable. A Video info group (caption, keywords, date taken) writes the QuickTime keys and the movie header; every QuickTime key is editable, removable or addable; every timed-metadata track (face detection, Live Photo info, orientation, segment ID) can be removed: the track is dropped and its samples are zeroed in place. Nothing is uploaded: files are parsed and rewritten in the browser, and payload bytes are copied through untouched. Multi-value tags are edited one value per line. Every text metadata field is editable and every metadata block is removable; only structures needed to decode the file (headers, tracks, image data) are protected. Shows C2PA manifests (read-only: claim details, signer and timestamp as claimed, with an on-demand data-hash check and a remove option) and Suno provenance strings compared against the manifest times. Technical details include MP3 VBR/CBR, average bitrate and gapless delay/padding. Installable as a PWA.

- Test: `node --test`
- Deploy: CI deploys on push to `main` (`npx wrangler@4 deploy`, needs repo secrets `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`).

Not yet supported (rejected with a message): Ogg FLAC/Speex/Theora, RF64 (64-bit WAV). Out of scope: documents and archives, fragmented-MP4 editing, ID3v1/APEv2 editing, timed-text remux, C2PA signature/certificate validation.
